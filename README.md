# RPyG
A Text based RPG in Python, mostly as an excuse to play with more advanced python/OOP concepts

Run `main.py` in your terminal and have fun.

Starting with v3 running via (UV)[https://docs.astral.sh/uv/] with either of these commands
```shell
uv run --from git+https://github.com/Andrew-Jayne/RPyG rpyg
```
```shell
uvx --from git+https://github.com/Andrew-Jayne/RPyG rpyg
```
